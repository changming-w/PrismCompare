# 使用说明

顶部工具栏右侧的“设置”箭头按钮单击收起来源与参数区域，再点展开，路径和参数不变。混合比例与分割位置滑块只在对应模式显示，差值增益只在差值模式显示。

顶部图标工具栏提供文件/历史、比较/停止、四种底部对比模式、交换、缩放、导航和帮助。鼠标悬停显示名称及已有快捷键；高亮表示当前图片显示模式。文字菜单仍然可用。

## 文件或文件夹

左侧默认自动隐藏：鼠标移到窗口左边缘的细条即可展开，移出浮层后收起。“常驻”可固定为左侧列表，设置会记住；自动模式不挤占图片区域。重复的导航、导出、交换和适应按钮已集中到顶部，底部保留查看参数和像素信息。

“打开文件”可一次选 2–4 个文件，也可以用 A–D 各自的“选择”按钮。
“添加文件夹”逐个添加来源；填好后点击“开始比对”。拖放 2–4 个同类型来源也可以。
数量决定当前激活的 A–D。改变来源或数量后重新开始，避免把旧结果当成新结果。
文件夹按**完整相对路径（含文件名大小写）**配对，不按拍摄时间或图像内容自动匹配。

左侧列表可显示每个来源的缩略图，或切换为文件名。搜索相对路径、仅图片、隐藏已确认相同均可组合。
缺失来源保留空位，不将后一个文件错配过来。扫描遇到无权限路径会提示，可导出列表查看错误。

## 图片

顶部“基准来源”可以指定图片或文件夹，图片右键也可“设为基准”。“对齐”或右键“自动缩放”将其他图片按基准当前显示尺寸等比缩放；宽高比不同时不拉伸。此操作不重采样原始数据，不改变比较指标。

图片右键提供对齐基准、适应窗口、原始大小、适应宽度（水平缩放）、顺时针/逆时针旋转 90°、重置旋转和在文件夹中定位。旋转仅影响当前图片视图，不改动文件或 PSNR/SSIM 计算；光标仍显示原始图像坐标与码值。

顶部“交换”：两路交换 A/B，多路交换当前基准与底部选中的来源。仅交换当前打开的图片，不改变文件夹路径或列表，不重新扫描或读取图片；切换到下一项恢复原始来源顺序。两路直接复用已有指标，多路在已加载像素上更新基准相关指标。

图片光标为小十字，同一原始像素坐标同步标记到各图。底部对比区左侧显示 9×9 像素细节、原始 RGB/A 码值、缩放与容差；右侧显示独立红蓝差异图。PSNR、SSIM、MAE、最大差值和超阈值比例集中显示在左下角。通过底部来源选择器切换当前基准与另一来源的比较；基准仍在顶部选择。可拖动上下分隔条调整高度，或关闭“底部对比区”。偏移固定为 (0,0)，当前没有图像配准或偏移校正。

直方图以小型高透明度浅色填充图叠加在每个对比窗口左上角，保持固定位置和大小，不随图片缩放、平移、旋转或窗口尺寸变化而改变。顶部“直方图”选项可选择 RGB、Y、HSV 或“关闭”；不占用额外图片高度，也不阻挡鼠标缩放和平移。

选择基准 A/B/C/D 后，其他图片分别与该基准比较。上方固定显示原图；底部支持红蓝差异、绝对差值、半透明叠加、滑动分割。
容差、差值、混合和分割结果统一显示在底部对比区，上方始终保留原图。切换结果模式会自动显示底部区域。分割时可直接拖动底部图片上的竖线手柄，位置与设置区域的滑块双向同步。
叠加/分割旁的滑块控制比例；差值增益仅用于绝对差值的显示，不修改数值指标。

红蓝阈值使用每个像素的**最大通道绝对差**：超过阈值为红色，非零但在阈值内为蓝色，相同为黑色。
可选比较 Alpha；RGB 没有 Alpha 时视为完全不透明。两张都没有 Alpha 时，指标只使用 RGB 三通道。
容差只改变红蓝分类和超阈值计数，不改变 PSNR、SSIM、MAE 等原始指标。

滚轮缩放，鼠标拖动平移。开启同步视图后，其他图跟随；原尺寸相同的图可逐像素检查。
右下指标相对当前基准，鼠标悬停指标区域可查看具体计算口径。

### 你的 10bit PNG

对于按 `v16 = v10 << 6` 保存的 16bit PNG：

1. 选择“10bit 左移6位”。8bit SDR 仍按 255 归一化，16bit HDR 按 65472 归一化。
2. 若希望阈值表示原始 10bit 码值，单位选择“10bit 码值”。
3. 指针栏显示文件中的**存储数值**（16bit），不自动右移，以便检查低位。

普通满范围 16bit 图片应选择“自动 8/16bit”，其归一化除数为 65535。
混合位深比较使用各自归一化的码值；这不是 HDR/SDR 亮度转换。

### 直方图与指标

- RGB：三条通道曲线；Y′：按所选 BT.709/BT.2020/BT.601 加权；HSV：色相、饱和度、明度。
- 使用全分辨率像素统计 256 bins。HSV 横轴归一化显示，H 对应 0–360°，S/V 对应 0–1。
- PSNR：归一化范围 1 的均方误差，完全相同显示 ∞。
- SSIM(Y′)：所选 Y′ 权重，11×11 高斯窗口，σ=1.5，K1=.01，K2=.03，population covariance；平均时去掉窗口边缘，小图自动减小奇数窗口。
- MAE、最大差值：以所选阈值单位（255/1023/65535）换算显示。
- 不做图像自动配准；尺寸不同则明确提示不可计算。
- 相似度不等同于人眼观看质量，也不表示两张图具有相同实际屏幕亮度。

## 文本、代码与文档

各来源使用公共对齐行轴。修改行红色、插入行绿色、缺失占位灰蓝色；代码有基础语法着色。
“忽略行首尾空白”只忽略首尾，不删除字符串内部空白。
DOCX 读取正文与表格；PDF 提取文字，不做 OCR；Excel 读取工作表值和公式，不计算公式。
扫描 PDF 无文字时明确提示，不将两个空提取结果误认为文档相同。
未知二进制文件以最多 64 KiB 十六进制预览，截断时不会判定完整文件相同。

## 最近比较与紧凑显示

“历史”保存最近 30 组成功打开的文件/图片/文件夹，可直接恢复路径、基准、递归和 SHA-256 选项。原文件缺失会报错，不会自动替换。清空历史只删记录，不删数据。“文件”菜单仍能导入会话。
文件列表仅显示 A–D 来源列，完整路径和状态通过悬停查看。图片名称、尺寸和位深显示在各图片视口底部的半透明一行文字中。

左下角指标随直方图选择：RGB 为 RGB PSNR/MAE 与 RGB 三通道平均 SSIM；Y 为所选 Y′ 权重；HSV 的色相采用圆周距离，并显示 SSIM(V)。无定义色相（灰色/黑色）不计色相差。PSNR/SSIM/MAE 不含 Alpha。差异图、最大差和超阈值计数使用所选 RGB/Y/YUV/HSV 的最大通道差；勾选 Alpha 且有 Alpha 通道时也参与判定。关闭直方图保留最近一次指标类型。选项会在正常退出时记忆。

“比较”重新扫描当前来源及重新计算；“停止”取消后台任务，空闲时禁用。图片解码后先显示，完整指标后台完成。缩略图优先级较低，调容差不再重复解码或重算 SSIM。重新比较会清空解码缓存。

## 实时容差、后台缩略图与全屏

拖动容差滑块时差异图持续更新，原分辨率指标不会因拖动而降采样。后台缩略图会持续加载所有项目，隐藏侧边栏也继续；“停止”可取消，侧边栏“刷新”可重新扫描并恢复加载。文件新增、删除或被覆盖后请点击刷新，当前选中项目若仍存在会保留。

“全屏”或 F10 查看当前组已载入的图片，顶部 A/B/C/D 按钮、字母键或左右方向键切换。切换复用内存图像，保留缩放和位置；F 适应窗口、1 原始像素、Esc/F10 退出。F11 专注模式同时显示当前组所有图片，F10 全屏模式一次显示其中一张。

右键一次超过四个来源会拒绝本批选择，下一次重新选择 2–4 个开始新组。关闭窗口立即断开旧窗口的右键接收入口，不必等后台文件读取结束才能开始新的比较。

缩放滑块右侧的“100%”恢复原始像素显示，“适应”将图片和底部视图适应窗口。光标移出图像时像素读数留空。容差更新不会弹出顶部进度条或改变视口位置。

## 通道联动与专注模式

YUV 选项使用全范围数字 Y′CbCr，Y′=KrR′+KgG′+KbB′，Cb=(B′−Y′)/(2(1−Kb))+0.5，Cr=(R′−Y′)/(2(1−Kr))+0.5；系数来自所选 BT.709/2020/601。HSV 的 H 差取圆周最短距离，灰/黑的无定义色相不计差。各通道归一化后用所选 8/10/16bit 码值单位显示容差。所有通道模式下，红色表示超过容差，蓝色表示非零但未超容差，黑色表示该模式下无差异；这不等于 RGB 原始像素完全相同。

左下角七行表格固定显示比较模式、PSNR、SSIM、MAE、最大差、超阈值数量和比例。切换模式同步更新直方图、指标、红蓝差异图及绝对差值图；混合/分割保持原图展示。

F11 专注：菜单、工具栏、侧边栏、底部对比区及信息叠层隐藏，图片窗口零间隔，缩小后的空白为黑色。鼠标移到顶部，悬浮显示缩放控制条（减号、滑块、加号、适应窗口、100%），移开自动隐藏；不占图片布局空间。Esc 或 F11 退出并恢复原窗口布局。
