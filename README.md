# Prism Compare · 棱镜比对

Windows 图片、文本、代码和文档内容比较工具。2–4 路文件或文件夹，来源只读。

## 直接使用

推荐双击 `releases/PrismCompare-0.1.11-x64.msi` 安装，可选择安装目录，并创建桌面、开始菜单和资源管理器右键入口。通过 Windows 设置中的“已安装的应用”卸载。

右键文件或文件夹 → **使用 Prism Compare 比较**。先加入一个来源，再右键另一个来源可加入同一比较窗口，最多 4 路。Windows 11 的传统右键项可能位于“显示更多选项”中。超过 4 路会提示，不会覆盖已有来源。文件与文件夹不能混为一组，切换类型会开始新的一组。

便携方式：

打开 `dist/PrismCompare/PrismCompare.exe`。首次使用可以点击“示例体验”。

分发时请复制 **整个 `dist/PrismCompare` 文件夹**，不能只拿走 exe；`_internal` 是运行所需依赖。打包版本无需另外安装 Python。

## 打开修改

1. 用 VS Code 打开 `PrismCompare.code-workspace`，或直接打开本项目文件夹。
2. 本机已建好 `.venv`。双击 `run.cmd` 可运行源码；VS Code 按 F5 可调试。
3. 修改 `src` 后重新运行即可，开发时不需要重新打包。
4. 要更新 exe，双击 `build.cmd`，或运行 `scripts/build.ps1`。
5. 要更新 MSI，先完成 exe 打包，再双击 `build_msi.cmd`。本机的 `.tools/wix314` 已准备好；新电脑也可执行 `scripts/build_msi.ps1 -WixBin "WiX 工具目录"`。安装清单由 `scripts/make_installer.py` 生成。

MSI 构建使用 [WiX 3.14.1 官方二进制工具](https://github.com/wixtoolset/wix3/releases/tag/wix3141rtm)，无需修改系统环境。安装后的程序不依赖 WiX 或 Python。

新电脑建议安装 **Python 3.13 x64**，然后双击 `setup.cmd`。如果项目被移动，建议重新创建 `.venv`；项目源码和打包程序都不依赖原来的绝对路径。

## 已实现

- 2、3、4 个文件；2–4 个文件夹按相对路径匹配，支持子目录。
- 文件列表切换缩略图/文件名；每个来源单独显示图片缩略图，缺失文件明确标注。
- 图片并排或四宫格；任意来源设为基准；同步缩放、平移、原始像素查看。
- 原图、红蓝阈值差异、绝对差值、半透明叠加、滑动分割。
- Y′、RGB、HSV 全图直方图，可切换对数纵轴；Y′ 权重支持 BT.709、BT.2020、BT.601。
- 原分辨率 PSNR、SSIM(Y′)、MAE、最大差值、超过阈值的像素数量和比例。
- 8bit / 16bit 整数图片；专门支持 `v16 = v10 << 6` 的 PNG 数值解释。
- 文本/代码多路逐行对齐、增删改高亮、简单语法着色和差异导航。
- DOCX 正文和表格、PDF 可提取文字、XLSX/XLSM 单元格值及公式的内容比较。
- 会话保存/加载、结果列表 CSV 导出、拖放文件、取消后台任务。
- Windows 系统标题栏、原生文件选择窗口、菜单和快捷键；跟随系统/浅色/深色主题。

## 测试

在本项目目录运行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe tests\ui_smoke.py
```

打包测试：

```powershell
.\dist\PrismCompare\PrismCompare.exe --smoke-test validation\packaged
```

截图和 JSON 结果保存在 `validation`。界面测试使用独立配置目录，不修改正常使用的偏好。

## 重要说明

- 文档对比是**内容提取比较**，不是 Word/PDF 页面版式比较；不执行 OCR、宏或代码。
- 不支持旧 `.doc/.xls`、PPT/PPTX 的内容解析；请先转换为支持的格式。
- 图片默认按存储像素直接比较，不做配准、缩放匹配、ICC 色彩管理或 HDR 显示映射。尺寸不同时不生成误导性的像素指标。
- GIF 仅比较第一帧。Y′ 是非线性码值加权，不是 nit；HSV 也基于码值。
- 16bit 原始数值参与指标计算，8bit 转换仅用于屏幕预览。
- 默认目录扫描只判断存在性和大小，“待校验”不代表相同。SHA-256 精确校验会读取全部内容；打开单项后会计算其图片或文本内容差异。
- 文本超过 80 万字符/12000 行、PDF 超过 200 页会标注截断，不能据此判定完整内容相同。
- 首版不提供文件同步、合并写回、删除、批量改名或安装驱动，避免误改原始数据。

更多操作见 [使用说明](docs/USER_GUIDE.md)，开发入口见 [架构与开发](docs/DEVELOPMENT.md)。

## 0.1.9 更新

- “历史”按钮保存最近 30 组成功打开的文件/图片/文件夹来源，重开时恢复来源类型、基准和扫描选项；缺失路径由后台扫描明确报错。
- 主要选项退出时保存，包括比较模式、直方图、码值单位、容差、布局、列表样式和显示开关。
- 图片文件名、基准、尺寸和位深合并为视口内底部半透明信息条，不再占据顶部两行。列表只显示 A–D 来源列，完整路径和状态见悬停提示。
- 图片解码后优先显示，直方图和指标后台完成；缩略图只在可见时加载并让当前图片优先。解码缓存上限 192 MiB，按文件大小和修改时间校验；重新比对清空缓存。
- 调容差复用直方图、PSNR、SSIM 和差值幅度，保持原分辨率精度。切换模式不再重复上传相同的大图。
- 下方指标随 RGB / Y / HSV 切换：RGB 的 SSIM 为三通道平均，Y 为所选权重的 Y′，HSV 显示 SSIM(V)。HSV 的 H 使用归一化圆周距离，灰色/黑色的无定义 H 不计差异；PSNR/MAE 对归一化 H、S、V 求平均。关闭直方图保留最近指标类型。指标不含 Alpha，红蓝容差仍为 RGB(A) 最大通道差，单独标注。

工具栏移除重复的“原图”和低频“会话”按钮；主视图始终是原图，底部统一使用容差/差值/混合/分割。会话导入保留在文件菜单。比较用于刷新来源，停止仅在后台任务运行时可用。

## 0.1.10 更新

- 容差拖动改为定时持续刷新，只重分类原尺寸差值；不等待拖动停止，不重算直方图或 SSIM。使用 OpenCV 查色表减少大图配色开销，仅刷新底部结果。
- 缩略图两路并发，当前可见项按需加载，后台持续遍历整组来源直到完成；不再等待主图指标计算结束。256 张内存缓存加本次运行的磁盘缓存，避免滚回时重复读取源图。刷新按钮重新扫描并更新主图与缩略图，尽量保留当前项目。底部显示加载进度，失败数独立显示。
- 新增“全屏”（F10 或图片右键），直接复用当前组的 QPixmap；A/B/C/D 按钮或方向键切换，保持查看位置及缩放，Esc 退出。缺失图片不参与切换。原“专注”（F11）不变。
- “历史”按钮移除下拉小箭头，点击仍打开历史菜单。
- 修复超量右键选择之后再次选择仍然超量的问题。仍支持 2–4 路；超量后下一次重新选取开始新组。关闭时立即注销 IPC，正在退出的旧窗口不会接收新选择。

## 0.1.11 更新

- 修复拖动容差时抖动：静默刷新，不切换布局内进度条；同尺寸图片只替换像素，不重新居中或适应。
- 左下角指标使用固定七行表格，缩放滑块增加 100% / 适应按钮，光标离开图像时清空读数。
- 差异图、容差判定与计数跟随 RGB / Y / YUV / HSV。YUV 为全范围 Y′CbCr，按所选 BT.709/2020/601 系数计算；HSV 色相采用环形距离。SSIM 在 RGB 使用三通道均值，在 Y/YUV 使用 Y′，在 HSV 使用 V。PSNR/SSIM/MAE 不含 Alpha，最大差及红蓝分类可包含 Alpha，并标注 +A。
- 全新的“专注”（F11）：只保留多图、零视口间隔、黑色空白填充；顶部悬停出现缩小、滑块、放大、适应窗口和 100% 控件，移开隐藏。Esc/F11 退出，恢复原界面。图标为眼睛，与 F10 全屏区分。
